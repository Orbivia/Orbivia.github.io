Politique de confidentialité de PrintLeft

Dernière mise à jour : 28 septembre 2026 · Éditeur : Orbivia

Résumé. PrintLeft fonctionne localement, sans compte, publicité, outil d’analyse ni serveur Orbivia. L’application ne transmet pas à Orbivia les données lues sur les puces NFC/RFID.

Données auxquelles l’application accède

Lorsque l’utilisateur approche un consommable compatible, PrintLeft peut lire en lecture seule l’identifiant de la puce NFC/RFID, des blocs de mémoire du tag, des compteurs, informations système et métadonnées techniques. L’utilisateur peut aussi ajouter localement un nom, un format, une note ou corriger des informations de rouleau.

Collecte et partage par Orbivia

PrintLeft ne collecte ni ne transmet ces données à Orbivia. L’application ne nécessite aucun compte, n’intègre aucun SDK publicitaire, aucun outil d’analytics et ne demande pas de permission Internet.

Stockage local et conservation

Les lectures sont stockées dans l’espace privé de l’application sur le téléphone. Elles sont conservées jusqu’à leur suppression par l’utilisateur ou la désinstallation de l’application. Les sauvegardes automatiques Android de ces données sont désactivées.

Export volontaire

L’utilisateur peut exporter ses lectures en CSV ou JSON via le sélecteur de fichiers Android. Si l’utilisateur choisit un service tiers, par exemple un stockage cloud, le fichier est alors traité selon la politique de ce service. Orbivia ne reçoit pas automatiquement ces exports et ne peut pas supprimer les copies créées hors de PrintLeft.

Suppression

L’utilisateur peut supprimer des rouleaux individuels ou effacer l’historique depuis l’application. La désinstallation supprime les données privées de PrintLeft présentes sur le téléphone. Aucun compte distant n’existe à supprimer.

Sécurité

PrintLeft utilise l’espace privé fourni par Android et n’expose pas de serveur distant. Les fichiers exportés ne sont pas chiffrés par PrintLeft ; leur protection dépend de l’emplacement choisi par l’utilisateur.

NFC/RFID

La fonction NFC est utilisée uniquement pour lire les tags compatibles lorsque l’écran Scanner est actif. PrintLeft n’écrit pas, ne réinitialise pas, ne clone pas et n’émule les tags.

Enfants

PrintLeft est un utilitaire technique destiné à un usage général et ne cible pas spécifiquement les enfants.

Contact

Pour toute question relative à la confidentialité : Orbivia — pierre.charlier@orbivia.fr.

Modifications

Cette politique peut être mise à jour si les fonctions de l’application ou ses traitements de données changent. La date affichée en haut de cette page indique la version en vigueur.

PrintLeft Privacy Policy

Last updated: September 28, 2026 · Publisher: Orbivia

Summary. PrintLeft works locally, with no account, advertising, analytics or Orbivia server. Data read from NFC/RFID tags is not transmitted to Orbivia.

Data accessed by the app

When the user scans compatible media, PrintLeft may read the NFC/RFID chip identifier, tag memory blocks, counters, system information and technical metadata in read-only mode. Users may also locally add a name, print size, note or corrected roll information.

Collection and sharing by Orbivia

PrintLeft does not collect or transmit this data to Orbivia. The app has no account system, advertising SDK or analytics SDK and does not request Internet permission.

Local storage and retention

Readings are stored in the app's private area on the device until the user deletes them or uninstalls the app. Android automatic backup of this data is disabled.

Voluntary export

Users may export readings as CSV or JSON through Android's file picker. If a third-party destination such as cloud storage is selected, that service's privacy policy applies. Orbivia does not automatically receive these exports.

Deletion

Users can delete individual rolls or erase history from the app. Uninstalling PrintLeft removes its private local data. There is no remote account to delete.

Security

PrintLeft uses Android private application storage and has no remote server. Exported files are not encrypted by PrintLeft.

NFC/RFID

NFC is used only to read compatible tags while the Scanner screen is active. PrintLeft does not write, reset, clone or emulate tags.

Children

PrintLeft is a technical utility for a general audience and is not specifically directed at children.

Contact

Privacy questions: Orbivia — pierre.charlier@orbivia.fr.
